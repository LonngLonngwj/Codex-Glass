Codex-Glass 3.1.1 · Windows 桌面额度浮窗

支持 Windows 10 1809 及以上 / Windows 11，64 位。
本软件是独立社区工具，与 OpenAI 没有隶属关系。

无需安装 Python。显示真实额度需要本机已有可用、已登录的 Codex CLI。
跟随 ChatGPT 只决定浮窗何时显示；显示的数据是 Codex 额度。

安装到当前用户目录，无需管理员权限。安装程序提供可选的桌面快捷方式与 Windows 登录守候；以后也可以在浮窗菜单中更改。
关闭客户端时浮窗隐藏，轻量后台继续守候，以便下次启动客户端时重新显示。

GPLv3 开源分享版，源码与依赖许可随包提供。安装、更新与卸载不会删除个人偏好；不会写入或附带作者的账号数据。
